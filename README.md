Kampüs Etkinlikleri

Projenin Amacı

Üniversite öğrencilerinin kampüs etkinliklerini kolayca keşfetmesi için hazırlanmış bir web sitesidir.

Sayfalar

* Ana Sayfa (index.html): Proje tanıtımı ve diğer sayfalara yönlendirme.
* Etkinlikler (etkinlikler.html): Etkinlik kartları ve etkinlik başlığına göre arama.
* Hakkımızda (hakkimizda.html): Proje ve amacı hakkında bilgi.

Kullanılan Teknolojiler

* HTML
* CSS
* JavaScript

Çalıştırma

Projeyi GitHub Codespaces üzerinde açın ve index.html dosyasını tarayıcıda çalıştırın. Yerel sunucuyla çalıştırmak için terminalde python3 -m http.server 8000 komutunu kullanabilirsiniz.
